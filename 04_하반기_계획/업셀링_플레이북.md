# 업셀링 플레이북 — 상반기 검증된 고배수 모션

> 기준일 2026-06-22 / ⚠️ 대외비. 금액 외부 공유 금지.
> 핵심: 신규 로고보다 **기수주 현장의 객단가 확대**가 신뢰 기반이라 성공률·효율 최고.

## 1. 검증된 사례 (상반기)

| 현장 | 초기 스코프 | 초기 금액 | 업셀 내용 | 최종 금액 | 배수 |
|---|---|---:|---|---:|---:|
| 거제 상동 2지구 | AR(증강현실) HW + 커뮤니티 영상 | 56,000,000 | 투명 LED 사이니지 3개 추가 + 영상 콘텐츠 + 개발 | **205,780,000** | **3.7x** |
| 송도 G5 | 유닛(내부세대) VR만 | 58,000,000 | 옵션 선택 솔루션(옵션몰) 기능 추가 | **94,000,000** | **1.6x** |

→ 두 건 합산: 초기 1.14억 → 최종 3.0억. **업셀로만 +1.86억 창출.**

## 2. 업셀 패턴 분석 — 무엇이 주효했나

1. **하드웨어 증설**(거제) — HW가 한 번 들어간 현장은 추가 사이니지/LED 설치 시
   콘텐츠·개발이 자동으로 따라붙어 배수가 가장 큼(3.7x). 단가표상 콘텐츠+개발이 HW에 종속.
2. **기능 모듈 추가**(송도) — VR만 들어간 현장에 옵션몰(50M)을 얹어 1.6x. 분양 단계 →
   옵션선택 단계로 생애주기 한 칸 전진.
3. 공통: **이미 신뢰가 형성된 현장**이라 신규 영업 대비 클로징 빠르고 저비용.

## 3. 재현 가능한 업셀 시퀀스 (제안 디폴트화)

기수주/진행 현장은 본계약 시점에 아래 후속 제안을 **기본 옵션으로 미리 설계**.

1. **HW 증설 라인** — LED/사이니지/키오스크 추가 → 영상·개발 콘텐츠 동반 (거제형, 최고 배수)
2. **옵션몰 라인** — 유닛 VR 현장에 옵션몰(50M, 2차부터 48M) 부착 (송도형)
3. **영상 라인** — AI 영상(25M~)·실내영상으로 광고 활용도 강조
4. **생애주기 라인** — 옵션몰 고객에 시공 가이드·관리 자가검진 파일럿(블루오션)

## 4. 하반기 적용 — 업셀을 명시적 레버로

- 상반기 기수주 17개 현장 전수에 대해 "업셀 가능 라인" 태깅 → 후속 제안 리스트화.
- 우선 대상: HW 들어간 현장(거제 추가 여지), 유닛만 들어간 현장(옵션몰 부착).
- 웜 파이프라인의 옵션몰 건(계룡 평택·천안, 송도 옵션몰 추가)도 동일 모션의 연장.
- **목표 기여**: H2 레버 A(기존 계정 확장 7.0억) 중 업셀 비중을 핵심으로 운영.
  상반기 업셀 +1.86억 실적 → 하반기 현장 수·HW 베이스 확대 시 3억+ 기여 가능(가정, 확인 필요).
