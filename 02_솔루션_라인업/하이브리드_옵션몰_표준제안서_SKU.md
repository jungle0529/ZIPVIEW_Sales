# 하이브리드 옵션몰 표준 제안서 (SKU) — 2026 하반기

> ⚠️ 대외비. 견적은 공식 단가표 기반 구성 예시 — 실제는 사업지별 협의(확인 필요).
> 재사용 대상: 포스코(도입 확대)·DL·GS·삼성물산·현대 등 대단지 선제 제안 공통 무기.
> 근거 문서: `02_솔루션_라인업/집뷰_솔루션_단가표_2026.md`, Option-Mall 레포(송도 G5 프로토타입).

## 1. 한 줄 가치 제안

"분양 시점엔 핵심 타입만 VR로 가볍게 시작하고, 옵션행사 시점에 전 타입 셀프 견적 옵션몰로
확장하세요. 초기 부담은 낮추고, 옵션 매출과 계약 전환은 높입니다."

## 2. 문제 → 솔루션

- **문제**: 전 타입 VR 제작은 비용·납기 부담이 커 옵션몰 도입의 진입장벽. 단순 유닛 VR은
  업체 평준화로 차별화가 약함.
- **솔루션**: 뷰어 모드(`vr`/`image`/`none`)를 혼합하는 **하이브리드 옵션몰**. 우측 옵션 선택·
  실시간 견적·견적서 출력은 전 타입 동일, 좌측 비주얼만 타입별로 차등 → 비용 최적화 + 셀프
  견적 경험으로 차별화(데이터 모델·견적 엔진·의존성 로직은 복제 난이도 높음).

## 3. 2단계 구성 (Phased) — 핵심 세일즈 구조

| 단계 | 시점 | 제공 | 발주처 효익 |
|---|---|---|---|
| **1단계: 분양** | 분양 개시 | 사이버 홈페이지 + 핵심 대표 타입 VR(2~4개) + 인프라(온라인 무상) | 초기 비용↓, 빠른 오픈, 분양 마케팅 즉시 활용 |
| **2단계: 옵션행사** | 계약/옵션행사 | 옵션몰 시스템 + 잔여 전 타입 리스트형(`image`/`none`) + 옵션 데이터·견적 엔진 | 셀프 견적으로 옵션 매출↑, 오프라인 상담 비용↓, 리드 DB 확보 |

→ 한 사업지에서 **매출이 2회 발생**(분양 수주 → 옵션행사 추가 수주). 시행 주체와 계약 시
특히 강력(옵션행사 추가 집행 권한이 시행사에 있음 → `업셀링_플레이북.md`).

## 4. 견적 구성 예시 (단가표 기반, VAT 별도)

> 사이버 홈페이지 30M / 유닛 VR 6M(~100㎡)·8M(101~200)·11M(201㎡~) / 옵션 제작·추출 2M·타입 /
> 옵션몰 개발 **50M(2차 사업지부터 50%=25M)** / AI 영상 25~40M / 오프라인 터치존 15M(옵션).

### 소형 (≤500세대, ~5타입)
- 1단계(분양): 사이버 홈페이지 30M + 핵심 VR 2타입(16M) = **약 46M**
- 2단계(옵션행사): 옵션몰 50M + 옵션 데이터(전타입) ~10M = **약 60M**
- 합계 레인지: **약 100M**

### 중형 (500~1,500세대, ~8타입)
- 1단계: 사이버 홈페이지 30M + 핵심 VR 3타입(24M) + AI 영상 25M = **약 79M**
- 2단계: 옵션몰 50M + 옵션 데이터(VR 3 + 리스트 5) ~16M = **약 66M**
- 합계 레인지: **약 145M**

### 대형 (1,500세대+, 10타입+ / 예: 검단 2,857세대)
- 1단계: 사이버 홈페이지 30M + 핵심 VR 4타입(32M) + 커뮤니티 VR + 단지투어 Ver.02(50M) + AI 영상 40M
  = **약 150M+**
- 2단계: 옵션몰 50M + 옵션 데이터 다타입(~30M) + HW(터치존·키오스크 옵션) = **약 90M+**
- 합계 레인지: **약 240M+** (HW 결합 시 추가 상향)

> 2차 이후 동일 시공사 사업지는 옵션몰 개발 50% 할인 → **횡전개일수록 마진·수주 유리.**

## 5. ROI 스토리 (제안 화법)

- **분양사/시행사**: 옵션 셀프 견적으로 옵션 채택률·객단가 상승, 모델하우스 상담 인력·운영비
  절감, 비대면 계약 환경. 분양 마케팅 콘텐츠(VR·AI 영상)를 광고로 재활용.
- **단계적 도입**: 분양 시점 소액으로 시작 → 성과 확인 후 옵션행사 확대(리스크 분산).
- ※ 효익은 사업지 여건에 따라 상이(구체 수치는 단정 금지, 확인 필요).

## 6. 레퍼런스

- **더샵 송도그란테르 G5 옵션몰**(포스코이앤씨) — 유닛 VR 58M에서 옵션 솔루션 추가로 94M 확장.
  하이브리드 옵션몰 프로토타입 보유(데모 가능).
- 옵션 DX: GS 옵션몰 고도화, 엘리프 세종 옵션 행사 DX, 송도 G5 옵션 솔루션.

## 7. 도입 프로세스 / 납기

1. 사업지 타입·옵션 자료 수급 → 2. 뷰어 모드 구성(타입별 vr/image/none) 확정 →
3. 1단계(분양) VR·홈페이지 제작(약 2~4주) → 4. 2단계(옵션행사) 옵션몰 구축·견적 엔진 연동 →
5. 파일럿/오픈. (정확한 납기는 타입 수·옵션 복잡도에 따라 협의)
