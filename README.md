# ZIPVIEW Sales — 하반기(H2) 매출 계획 워크스페이스

올림플래닛 분양 파트(VR·XR 솔루션 및 결합 하드웨어·서비스) 하반기 매출 달성을 위한
영업 분석·전략·실행계획 작업 공간.

## 작업 흐름

전반기 실적에서 **뭐가 통했고 뭐가 안 통했는지**를 분석해, 하반기에 **어떤 세그먼트 ×
어떤 솔루션 조합 × 어떤 채널**에 자원을 집중할지 결정한다.

1. 자료 수집 (`01_data_전반기실적`, `02_솔루션_라인업`)
2. 분석 — 세그먼트·솔루션·채널별 성과 패턴 (`03_분석`)
3. 하반기 실행계획 — 목표 분해, 파이프라인, 액션플랜 (`04_하반기_계획`)

## 디렉터리

| 폴더 | 채울 내용 |
|------|-----------|
| `01_data_전반기실적` | 수주/계약 건별 데이터: 고객사·현장 유형, 솔루션 구성, 계약 규모·마진, 리드 유입 경로, 영업 사이클, 드롭된 딜과 사유 |
| `02_솔루션_라인업` | 분양 파트 판매 가능 솔루션·하드웨어 목록, 가격대, 원가 구조, 납기·구축 리드타임, 신규 추진 품목 |
| `03_분석` | 전반기 성과 분석, 세그먼트·솔루션 조합별 수익성, 승/패 요인 |
| `04_하반기_계획` | 매출 목표 분해, 타깃 세그먼트·계정, 파이프라인, 분기별 액션플랜 |

## 보안

대외비 수치·고객/파트너 데이터·미공개 IR 정보는 외부 공유용 산출물에 임의 포함 금지.
개인정보(연락처 등)는 문서에 불필요하게 남기지 않는다.
